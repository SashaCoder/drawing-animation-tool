# Drawing & Animation Tool - Frontend

A simple drawing tool built with React and Vite that allows freehand drawing on an HTML canvas.

## Features

- 🎨 Freehand drawing with mouse drag
- 🗑️ Clear canvas functionality
- 💻 Cross-platform (Mac + Windows)
- ⚡ Fast development with Vite

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
frontend/
├── src/
│   ├── App.jsx          # Main application component with canvas logic
│   ├── App.css          # Application styles
│   ├── main.jsx         # React entry point
│   └── index.css        # Global styles
├── index.html           # HTML template
├── vite.config.js       # Vite configuration
└── package.json         # Dependencies and scripts
```
